# AI 交易智能体 · 建设计划

**一句话目标：** 做一个能看能管的 AI 交易助手网站。先用「模拟资金」自动交易 BTC/ETH，所有风控由固定规则把关，AI 只负责分析和写复盘，**绝不直接下单**。真钱要等模拟期验收通过后再讨论。

---

## 先说明几处和文档不一样的地方（不影响效果）

| 文档写的 | 我这里的做法 | 原因 |
|---|---|---|
| Python + 终端面板 | 网页应用（后台 + 网页界面） | 你想要「能访问的界面」，这个工作室本来就做网站 |
| 连交易所测试网下单 | 第一阶段用**内置模拟账户**，行情用真实数据 | 不需要你注册交易所、不用给 API 密钥，零风险 |
| Telegram 告警 | 先做网页内的「事件/告警」页；Telegram 放到后期可选 | 先把核心跑通 |
| 30 天模拟期 | 系统会照做，但这 30 天需要真实时间等待 | 这一步无法压缩 |

**默认选择（你可以改）：** 加密货币永续合约 · BTC 和 ETH 两个币 · 1 小时 K 线为主、4 小时确认 · 起始模拟资金 10,000 USDT · 风控数值完全沿用文档（单笔 0.5%、日亏 2%、回撤 10% 锁仓）。

---

## 分几次交付给你（每次交付你都能在网页上看到东西）

### 第 1 次交付：行情 & 市场状态看板
- 你会看到：BTC/ETH 实时价格、K 线图、资金费率、持仓量、恐惧贪婪指数。
- 每个币会贴一个标签：**趋势 / 震荡 / 高波动 / 低流动性 / 不明确**（按文档里的公式算，不靠 AI 猜）。
- 同时开始存历史 K 线（至少 1 年）供回测用。

### 第 2 次交付：回测实验室
- 两个入门策略：**趋势跟随**、**均值回归**。
- 点一下就能看到：「如果过去一年按这个策略做，会怎么样」——收益曲线、最大回撤、胜率、交易次数等。
- 已计入手续费、滑点、资金费率；严防「偷看未来数据」。
- 附带滚动验证（换不同时间段反复测试）和参数稳定性测试，判断策略是不是「碰巧好看」。

### 第 3 次交付：风控大脑 + 模拟自动交易
- 系统每小时自动运行：看行情 → 判断市场状态 → 选允许的策略 → 风控审核 → 模拟下单。
- 风控红线写死在程序里，策略不能绕过：仓位大小自动计算、日亏 2% 停手、回撤 10% 全平锁定（需你手动解锁）、数据异常自动暂停。
- 页面上有一个大大的 **「紧急停止」按钮**。

### 第 4 次交付：交易驾驶舱（你日常看的主界面）
- 账户净值曲线、当前持仓、浮动盈亏、每笔交易记录、订单状态。
- 「事件与告警」列表：开平仓、风控触发、自动暂停、系统重启等。
- 设置页：查看/调整风控参数（改动会留记录）。

### 第 5 次交付：AI 研究员 & 每日复盘
- AI 每天自动写一份中文复盘：今天做了什么、哪个策略表现如何、出了什么异常、有什么改进建议。
- AI 可以对当前市场给「解读」和「策略建议」，但这些只是参考文字，**不会进入下单流程**。

### 第 6 次交付：验收清单页
- 把文档里的验收标准做成一张打勾表：样本外夏普 > 1、回撤 < 15%、交易 > 100 笔、模拟连续运行 ≥ 30 天、模拟 vs 回测偏差 < 20%……
- 自动统计、自动打勾。**全部打勾之前，系统不提供真钱模式。**

### 之后（视验收结果再定）
- Telegram 手机推送；接交易所测试网；最后才讨论用 ≤5% 资金小额实盘。

## 代码放在哪 & 怎么运行

- **开发和预览都在 Surf 里完成**：你不用自己装任何东西，每次交付直接在 Surf 里打开网页看效果。
- **定时任务和数据库**：Surf 环境自带定时任务（每小时自动跑交易逻辑）和数据库（存 K 线、订单、净值），第一阶段不需要你自己准备服务器。
- **提交到 GitHub**：每完成一次交付，我就把代码提交一次，并写好清楚的说明（这次加了什么），方便你随时查看、回退版本。
  - 需要你准备：① 在 GitHub 建一个空仓库（建议设为**私有**）；② 给我一个只授权这个仓库的访问令牌（Fine-grained token，只开放 Contents 读写权限）。到时我会一步步教你，大约 3 分钟。
  - 令牌只用来推送代码，不会写进代码里，也不会提交上去。
  - 仓库里会附一份 README，写清楚以后自己部署要怎么做。
- **要提前说明的一点**：30 天模拟期要求程序**一直在线**。如果 Surf 的运行环境不能保证 7×24 小时在线，到那一步我会给你两个选择：继续用 Surf 的发布功能，或者用 GitHub 上的代码部署到一台云服务器（每月几十元的那种），我来写好部署步骤。另外，行情数据走的是 Surf 的数据接口，自己部署时需要配一个 Surf 的 API 密钥，README 里也会写清楚。

## 你需要做的
- 每次交付后打开网页看看，告诉我「哪里看不懂 / 想改什么」就行。
- 不需要提供任何交易所账户或密钥（第一阶段）。
- 只需要提供一个 GitHub 空仓库 + 访问令牌（我会教你怎么弄）。

## 需要提前说清的事实
- 这套系统能保证「不因为程序错误亏钱」，但**不能保证策略赚钱**——是否赚钱只能靠回测和模拟期的数据说话。
- 第 1–6 次交付大约是几轮对话就能完成；但 30 天模拟期是真实时间，必须等。
