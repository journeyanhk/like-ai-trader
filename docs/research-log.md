# 研究日志（策略门）

规则（来自第二轮审查，写在这里就不再改）：

1. 先归因，再研究。归因只是诊断，不算研究次数，也不碰留出集。
2. 每一轮研究**最多 3 个假设**，必须在运行前写在本文件里（日期、内容、固定参数、通过线），写完提交 git 才能跑。
3. 假设必须有经济逻辑；**不允许**调参数（如把突破周期 120 改 140），**不允许**按币种挑选（如去掉 BTC）。
4. 每个假设只跑**一次**滚动验证，跑完不许改细节重跑。失败的也要记录。
5. 研究阶段的通过线：滚动验证样本外夏普 > 1.0，**并且**比基线高 0.3 以上（小于 0.3 的提升在 ±1.0 的误差里没有意义）。
6. 只有通过第 5 条的那一个候选（如果有多个，取提升最大的那个，事先约定）能碰留出集（2026-07-11 起的 90 天），**只跑一次**。留出集通过线：夏普 > 0、最大回撤 < 15%、交易频率与滚动验证期相差不超过 ±50%。三条都过 → 策略门通过；任一不过 → 候选作废，不回到第 2 步重试。
7. 全部不通过就是合法结局：「趋势突破 v1 在 2 年数据上未证明优势」。模拟盘照常跑满 30 天，实盘不开。
8. 研究只用 `lib/lab.js` 和 `scripts/research/`，不改模拟盘的决策路径（`simulate / backtest / paper / risk / strategies / regime / indicators / feed / config`），不碰模拟账户。

## 2026-10-09 归因诊断：夏普 1.21 → 0.77 是怎么掉的

脚本：`node backend/scripts/research/attribution.js`（约 70 秒，只读本地数据）。策略、参数网格、滚动验证规则与 `lab.js` 完全相同，只切换 5 个开关。审查报告列了 4 个原因，归因时发现还有第 5 个：**回测 #5 打开了「回撤 10% 锁定」，#4 没开**。

基线（#4 口径，5 项全关）：夏普 **1.32**，收益 26.93%，回撤 11.67%，270 笔。
（#4 当时是 1.21。差 0.11 来自之后的引擎修正，比如每个时间点只算一次权益；另外旧的资金费覆盖范围是近似还原的，按 2026-07-09 之后算真实。这个差值远小于 ±1.16 的误差。）

**按 #4 → #5 的顺序依次打开：**

| 打开 | 样本外夏普 | 变化 | 收益 | 回撤 | 笔数 |
|---|---|---|---|---|---|
| 基线 | 1.32 | | 26.93% | 11.67% | 270 |
| + 去掉最近 90 天（留出集） | 1.08 | **−0.23** | 15.57% | 11.67% | 237 |
| + 资金费改用 730 天真实数据 | 1.09 | +0.01 | 15.91% | 11.98% | 236 |
| + 5 币同组上限 60% | 1.00 | −0.09 | 14.13% | 11.98% | 236 |
| + 合约取整 / 最小下单量 | 1.00 | 0.00 | 14.11% | 11.95% | 236 |
| + 回撤 10% 锁定 | **0.77** | **−0.23** | 9.90% | 10.06% | 206 |

全部打开得到 0.77，和回测 #5 完全一致。说明归因脚本还原的就是 #5 本身。

**单独打开某一项（其余保持 #4 口径）：**

| 只打开 | 夏普 | 变化 |
|---|---|---|
| 去掉最近 90 天 | 1.08 | −0.23 |
| 真实资金费 | 1.32 | +0.01 |
| 同组上限 60% | 1.25 | −0.07 |
| 合约取整 | 1.32 | 0.00 |
| 回撤锁定 | 0.77 | **−0.54** |

**结论：**

1. **资金费、合约取整几乎没有影响**（合计 ±0.01）。730 天真实资金费算下来比旧的保守假设还便宜（样本外约 51 USDT，旧口径约 142）。所以「资金费吃掉利润」这个方向**不值得**花一个研究名额。
2. **去掉最近 90 天贡献 −0.23。** 原先 1.21 里确实有一部分是最近一段行情撑起来的。
3. **同组上限贡献 −0.07 到 −0.09。** 这是降风险的代价，属于预期之内。
4. **回撤锁定是最大的一项（−0.23 到 −0.54）。** 但它的性质和其他几项不同：回测里锁定在 **2026-04-29** 触发，之后**再也不解锁**，剩下两个多月样本外完全空仓。实际运营中，锁定后会人工检查再解锁。所以 0.77 里有一部分反映的是「回测没有模拟人工解锁」，而不是策略本身变差了。
5. **但这不改变结论。** 不算锁定时夏普是 1.00，仍然没有严格超过 1.0；1.00 和 0.77 的差距也在 ±1.06 的标准误差以内。**不能**因此改验收口径来「通过」。如果改了就是挪球门，正是审查报告警告的选择偏差。
6. 样本外约 1.15 年，夏普标准误差约 ±1.06。0.77 和 0、和 1.0 在统计上都区分不开。

## 2026-10-09 研究口径修正（第二轮审查回复，运行前确定）

1. **研究运行一律 ddLock=false。** 0.77 里有 −0.23 到 −0.54 来自「锁定后永不解锁」，这是没有建模的运营事件。如果用它做基线，任何碰巧避开 2026-04-29 那次锁定的过滤器都会白拿约 +0.5。
2. **基线改为 1.00**（当前配置、留出集之前、不开锁定）。**通过线改为 ≥ 1.30**（1.00 + 0.3）。
3. 每次运行另外报告「如果开锁定，会在哪些日期触发、共几次」，只作运营信息。假设每次锁定 24 小时后人工解锁，峰值从解锁时的净值重新计算。
4. 策略门 5 项按 ddLock=false 的运行计算。开了锁定的运行在验收页标注「运营口径，不作策略判断」，5 项显示为待定（回测 #5 即属此类）。
5. **可判定性：** 每个假设报告「被过滤的入场信号数 / 原入场信号数」（只统计拼接后的样本外那次运行）。比例 < 10% 或 > 70% 记为**不可判定**：不算通过也不算失败，不消耗留出集，不允许改阈值重跑。

## 第 1 轮研究：预注册（定稿，提交 git 后运行，每个只跑一次）

- 基线：趋势突破，当前配置，ddLock=false，留出集之前。预期样本外夏普 1.00（归因表中「去掉锁定」那一行）。基线会再跑一次确认，记作 `R1-baseline`。
- 一个假设判为**通过**，三条都要满足：可判定（过滤比例在 10%–70%）；样本外夏普 ≥ 1.30；策略门 5 项全过（夏普 > 1、回撤 < 15%、笔数 > 100、覆盖涨跌震荡、参数 ±20% 不崩塌）。
- 结论只有三种：通过 / 不通过 / 不可判定。
- 多个通过时，取样本外夏普最高的一个；并列时取笔数多的。最多一个进入留出集。
- 每个假设只在趋势突破上叠加一条入场过滤，其余一律不变（参数网格、风控、成本、同组上限、合约取整都不变）。
- 脚本：`scripts/research/hypotheses.js`。数据库里已有同名记录（`R1-H1` 等）就拒绝再跑。

| # | 假设 | 经济逻辑 | 固定规则（写死，不调） |
|---|---|---|---|
| H1 | 资金费极端时不顺势开仓 | 资金费极端说明同方向仓位拥挤，突破后容易被反向挤压 | 阈值 = 该币过去 90 天 \|费率\| 的 90 分位（最近排名法）。费率取时间戳 ≤ 信号 K 线收盘时刻的最近一次已结算值。费率 > +阈值不做多；费率 < −阈值不做空 |

### 留出集检验（只给通过者，只跑一次）

- 脚本：`scripts/research/holdout.js`。不是「通过」的拒绝运行；本轮已有人用过留出集的也拒绝。
- 参数：用 2026-07-11 之前 180 天，按同样的网格、同样的打分规则选出。
- 区间：2026-07-11 → 最近一根已收盘 K 线，ddLock=false。
- 通过线（三条都要过）：夏普 > 0；最大回撤 < 15%；每天交易笔数和滚动验证期相差不超过 ±50%。
- 结果：三条都过，策略门通过；任一不过，候选作废，不回到研究阶段重试。
- 全部不通过时，结论是「趋势突破 v1 在 2 年数据上未证明优势」。模拟盘照常跑满 30 天，实盘不开。
